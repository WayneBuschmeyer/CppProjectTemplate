# Security policy

## Supported versions

Security fixes are applied to the current public release line.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting when available instead of
opening a public issue with exploit details.

Include:

- affected version or commit;
- impact;
- reproduction steps;
- any suggested mitigation.

## Supply-chain policy

GitHub Actions are pinned to full commit SHAs. Version comments remain beside
the SHAs for human readability, and Dependabot proposes routine updates.

A pinned SHA provides immutability; it does not prove that the referenced code
is trustworthy. Action updates still require review.
